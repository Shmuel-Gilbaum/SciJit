scijit.optimize is an independent reimplementation, drop-in
compatible with the NumbaMinpack API (minpack_sig, hybrd, lmdif,
same return convention), which pioneered the cfunc-address ->
c_void_p -> bind(c) architecture this whole project builds on.
No NumbaMinpack code is vendored here (Fortran sources are from
fortran-lang/minpack; the callback plumbing was redesigned with
module-variable adapters to avoid the executable-stack failure on
hardened Linux), but the API design is Nicholas Wogan's — carrying
his MIT notice is the least we can do.
